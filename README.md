# osrs-grind

A tool for tracking Old School RuneScape "grinds" — skill levels, boss kill
counts, minigame rewards, and the items/unlocks they lead to. Grinds are
rarely a flat list: doing skill A and skill B unlocks boss C, which drops
items D and E, and so on. This app visualizes and tracks those dependency
chains as small, independent graphs rather than one master checklist.

Live at **https://grind.mattlove.dev**.

No accounts — each board is addressed by a random, unguessable URL
(the same pattern as Excalidraw or Figma share links). Bookmark the link
to come back to a board; anyone with the link can edit it.

The full design history and reasoning — domain model, data sourcing,
deployment architecture, decisions that got reversed and why — lives in
[`docs/DESIGN.md`](docs/DESIGN.md), not here. This file just covers
running the project locally.

## Stack

SvelteKit + TypeScript (`adapter-node`), Firestore for board data, a
build-time-generated catalog of skills/bosses/monsters/items scraped from
the [OSRS Wiki](https://oldschool.runescape.wiki), deployed to Cloud Run.
See `docs/DESIGN.md` for the reasoning behind each of these.

## Developing locally

```sh
npm install
cp .env.example .env   # real Firebase config, not secret - see the file's own comment
npm run emulator        # Firestore emulator, in one terminal
npm run dev              # in another terminal
```

Local dev always talks to the Firestore emulator, never production data -
this is automatic based on SvelteKit's dev mode, not something you
configure per-run.

Other useful commands:

```sh
npm run build    # production build (adapter-node)
npm run preview  # preview that build locally
npm run check    # typecheck
npm run lint     # prettier + eslint
```

## The catalog

`src/lib/data/catalog.json` (skills/bosses/monsters/items, with icons) is
generated by a scraper pipeline in `scripts/`, not hand-maintained. It's
committed to the repo; you don't need to re-run it to develop locally.
If you do want to regenerate it:

```sh
npm run scrape
```

This queries the OSRS Wiki's Bucket API in stages (see `scripts/` and
`docs/DESIGN.md`'s "Roadmap — catalog & search" for what each stage does)
and can take a while on a full run.

## Contributing

`main` deploys automatically on push (see `docs/DESIGN.md`'s "Roadmap —
deployment"), so it's locked to the repo owner. To contribute, fork the
repo and open a pull request from your fork.
